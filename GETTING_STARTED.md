## How to Test and Run Any Project Locally

Every project has its own dedicated folder. To run any project:

### Step 1: Open Terminal in the Project Folder
For example, to run Project 01 (Multi-Agent GraphRAG):
```powershell
cd C:\Users\0011TU\Desktop\Top-50-Advanced-Portfolio-Projects\01_enterprise_multi_agent_graphrag
```

### Step 2: Install Dependencies
```powershell
pip install -r requirements.txt
```

### Step 3: Run the Application
```powershell
python app.py
```

### Step 4: Open the Interactive API Docs
Open your browser and navigate to:
```
http://localhost:8000/docs
```
You can test the endpoints, inspect Pydantic schemas, and run sample queries directly from Swagger UI!
